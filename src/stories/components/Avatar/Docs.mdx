# Avatar with Initials

To create an avatar with initials, slot the initials into the main slot of the `zeta-avatar` component.
To change the color of the initials, set the `--avatar-initials-color` CSS variable to the desired color.

# Avatar with Image

To create an avatar with an image, slot an img element into the main slot of the `zeta-avatar` component.

# Avatar with Icon

To create an avatar with an icon, slot a `zeta-icon` into the main slot of the `zeta-avatar` component.

# Avatar with Status badge

Set `show-status` to `true` to show a default "available" `zeta-avatar-status-indicator`, sized to match the avatar automatically.

To show a different presence, or any other badge, slot your own content into the `status` slot instead, it takes precedence over the default.

# Avatar with Close icon

To show a close icon on an avatar, set `show-close` to `true`. The button renders a `zeta-avatar-status-indicator` with `status="close"`, and the component fires a `close` event when it's clicked.

# Avatar Status Indicator

`zeta-avatar-status-indicator` is the small colored badge used for `zeta-avatar`'s status slot and close button. It sizes itself
to `--avatar-status-indicator-size`, which `zeta-avatar` sets automatically to match its own `size` — set that variable directly
to use the indicator standalone at a custom size.
