# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately through [GitHub's vulnerability reporting](https://github.com/ZebraDevs/zeta-web/security/advisories/new). Include the affected version, steps to reproduce, and the impact you expect.

## Supported Versions

Security fixes are released for the latest version of `@zebra-fed/zeta-web` only.
